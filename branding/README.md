# Supplied TuklasTayo artwork

- Original: tuklastayo_logo_original.png, an unchanged copy of the user's attached Teal Culinary Journey Icon.png (1254 x 1254, RGB PNG). This source file stays outside Android resource/assets directories and is not packaged into the APK.
- Login: app/src/main/res/drawable-nodpi/tuklastayo_logo.png is the 360 x 360 resized original displayed at 108dp on app-owned Login. Discover guest Profile uses a neutral avatar and Sign In callback rather than this welcome logo; signed-in Profile uses its projected photo or neutral fallback.
- Native splash V1: app/src/main/res/drawable/tuklastayo_splash_icon.xml is a transparent 288dp vector, traced directly from the supplied original PNG. It contains only the white pin/cutlery and three #FFD11B rays, with even-odd transparent utensil cutouts. The original connected color-region outlines were traced, simplified within 0.65 source pixels (under 0.15dp at display scale), and uniformly scaled into an 88dp radius inside the native 96dp safe circle. No tile, heritage, landscape, ring, swoosh, baked shadow or white margin remains.
- Original and Login artwork are unchanged. Launcher resources are unchanged by Splash V1. Splash deliberately uses the traced principal symbol with flat white/yellow fills instead of the full composition.
- Launcher: adaptive icons use a full-bleed teal background sampled from the supplied image (#02564E) and a 432px transparent foreground at xxxhdpi (108dp). The existing composition occupies a centered 264px circle (66dp), leaving space within the visible 72dp mask for launcher masking/motion. The white outer margin, shadow and baked rounded corners are excluded. Normal and round PNG fallbacks exist at mdpi/hdpi/xhdpi/xxhdpi/xxxhdpi. The temporary Android robot and superseded WebP fallbacks were removed. No monochrome layer is declared: a separately approved one-color asset is needed for custom themed icons.

Splash dimensions reference: https://developer.android.com/develop/ui/views/launch/splash-screen . Manual device/preview verification remains necessary; resource compilation does not prove launcher or native-splash rendering on every Android/OEM version.
Splash V1 uses @color/tuklastayo_splash_background (#004C43) from one shared starting theme, with no night override. Normal Theme.Tuklas light/dark styles and native postSplashScreenTheme remain unchanged. Static icon/native exit behavior; no timers or Compose splash. Two attempted imagegen extractions were rejected because they damaged the cutouts; neither generated bitmap is shipped. The final code-native vector uses only the original PNG contours. Device cold-start testing in light/dark mode is still manual; the offline vector render is not a device screenshot.
